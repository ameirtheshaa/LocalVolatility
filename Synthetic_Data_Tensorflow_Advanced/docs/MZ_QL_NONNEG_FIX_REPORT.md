# Constraining the Quasi-Linear Mori–Zwanzig Backscatter Coefficient to be Non-Negative

_LocalVolatility · `Synthetic_Data_Tensorflow_Advanced/mz_spectral` · 2026-06-04 · Ameir Shaa_

## 1. Overview & Context

The `mz_spectral` package is a Mori–Zwanzig (MZ) spectral reduced-order model (ROM) for the Dupire local-volatility forward equation (paper §12). It splits the spectral state $\phi$ into a resolved (low-pass) block and an unresolved (high-frequency) block via a projector $P_R$, integrates the resolved-resolved (RRR) dynamics implicitly, and approximates the backscatter of the unresolved modes onto the resolved ones with a **quasi-linear (QL) closure**: a single scalar eddy coefficient $\nu_{\mathrm{QL}}$ multiplying a resolved-only second-derivative operator,

$$ B_{\mathrm{QL}}(\phi_R) \;\approx\; \nu_{\mathrm{QL}}\, P_R\, D_2\, \phi_R , $$

where $D_2$ is the same second-derivative stencil that appears in Dupire's spatial operator (without the $\eta\tilde{k}^2$ prefactor). The coefficient $\nu$ is fitted by least squares against the Markovian MZ residual computed from truth trajectories.

This work fixes a **sign defect** in the fit. The coefficient $\nu$ was being clipped symmetrically to $[-\nu_{\mathrm{clip}}, +\nu_{\mathrm{clip}}]$, which permitted the closure to select a *negative* (anti-diffusive) coefficient. On the exact constant-$\sigma$ Black–Scholes case — the cleanest possible test, with no Monte-Carlo noise — the fit pinned $\nu$ at the **negative** clip and thereby made the RRR+QL resolved-interior error *worse* than RRR-only. The goal was to constrain the fit to $\nu \ge 0$ so the closure can no longer pick a destabilizing anti-diffusive term, and to verify that this removes the worsening without breaking the other callers.

## 2. Theoretical Motivation

The QL term added to the resolved right-hand side downstream (in `ql_backscatter_term` and the IMEX integrator `integrate_rrr_ql`) is $+\nu\, P_R D_2 \phi$. The sign of $\nu$ has a definite physical meaning:

- **$\nu > 0$** is a positive eddy-diffusion. This is the physically-correct sign for a Mori–Zwanzig memory generated by integrating out high-frequency modes: the orthogonal (unresolved) dynamics dissipate energy, and their net effect on the resolved field is diffusive.
- **$\nu < 0$** is anti-diffusion — a backward-heat term. It is ill-posed and destabilizing: it amplifies high-wavenumber content of the resolved field rather than damping it. There is no legitimate regime in which the QL closure should select this sign; a negative $\nu$ is exactly the mis-signed memory that a propagator-sign analysis predicts as a failure mode.

The fitting problem for the global coefficient is a **single-parameter** least-squares problem. Per interior time-slice $i$ the residual to be explained is the Markovian MZ residual

$$ \mathrm{lhs}_i \;=\; P_R\, \dot{\phi}_i \;-\; L_{RR,i}\, \phi_{R,i}, \qquad \phi_{R,i} = P_R \phi^{\mathrm{truth}}_i, $$

with $\dot\phi_i$ a central difference, and the regressor is $q_i = P_R D_2 \phi_{R,i}$. The unconstrained ridge least-squares optimum is the pooled ratio

$$ \nu^\* \;=\; \frac{\sum_i \langle \mathrm{lhs}_i, q_i\rangle}{\sum_i \langle q_i, q_i\rangle + \text{ridge}} . $$

Because there is only **one** coefficient, imposing $\nu \ge 0$ has a closed form: the constrained optimum is simply the projection of $\nu^\*$ onto the feasible half-line, $\max(0,\nu^\*)$, capped above at $\nu_{\mathrm{clip}}$. This projection *is* the non-negative least-squares (NNLS) solution for a scalar regressor — no iterative NNLS solver is required. Replacing the clip lower bound $-\nu_{\mathrm{clip}}$ with $0$ therefore turns the symmetric clip into the exact NNLS estimate, and the closure can no longer choose an anti-diffusive coefficient.

This connects to the broader de-risk conclusion of the surrounding study (Step 0b of `run_mz_derisk.py`): on the exact constant-$\sigma$ case the *forward* price-side MZ memory is cosmetic. A negative $\nu^\*$ on smooth data is the signature of that fact — the resolved-mode eddy-diffusion does not help, and the unconstrained fit can only "improve" the unprojected normal-equation objective by adding a physically wrong, harmful term.

## 3. Implementation

The entire change is local to one function, `fit_nu_ql`, in [`mz_spectral/quasi_linear.py`](../mz_spectral/quasi_linear.py).

**Before** — the per-step and global coefficients were clipped symmetrically:

```python
nu_i      = float(np.clip(nu_i,          -nu_clip, nu_clip))
...
nu_global = float(np.clip(nu_global_raw, -nu_clip, nu_clip))
```

**After** — a keyword-only flag `nonneg: bool = True` selects the lower bound, and both clips use it:

```python
nu_lo = 0.0 if nonneg else -nu_clip
...
nu_i      = float(np.clip(nu_i,          nu_lo, nu_clip))
...
nu_global = float(np.clip(nu_global_raw, nu_lo, nu_clip))
```

Key properties of the change:

- **Default behavior changes for all callers.** `nonneg=True` is the default, so every existing call site (none of which passes the flag) now receives a non-negative $\nu$.
- **Return signature is unchanged.** `fit_nu_ql` still returns `Tuple[float, np.ndarray]` = `(nu_global, nu_steps)`. The addition is a new keyword-only argument with a default, so it is purely additive — no positional call breaks.
- **Legacy behavior is preserved as an escape hatch.** `fit_nu_ql(..., nonneg=False)` restores the symmetric clip $[-\nu_{\mathrm{clip}}, +\nu_{\mathrm{clip}}]$, retained only for before/after diagnostics.
- The docstring was rewritten to state the sign physics and the NNLS interpretation explicitly.

**Downstream consumers** (all read only the scalar `nu_global` and feed it to the IMEX integrator):

- `ql_backscatter_term(nu, P_R, D2, phi_R)` — `quasi_linear.py:22`, returns $\nu\,(P_R(D_2\phi_R))$.
- `integrate_rrr_ql(phi0, t_tilde, L_RR_rows, P_R, D2, nu)` — `validation.py:181`, IMEX rollout: implicit $L_{RR}$, explicit QL, $(I - \Delta\tilde t\,L_{RR})\phi^{n+1} = \phi^n + \Delta\tilde t\,\nu P_R D_2 \phi^n$.

**Call sites** (all use defaults; all now get the non-negative $\nu$):

- `mz_synthetic_setup.py:210` — oracle mode (fits from `phi_truth`).
- `data_driven.py:117` — data-driven mode (fits from `phi_data`; stores `nu_steps` as `nu_ql_steps`).
- `truncation_study.py:123` — truncation sweep over `keep`.
- `examples/run_mz_derisk.py:248` — Step 0b de-risk check.

## 4. Parameters & Design Choices

| Parameter / choice | Value | Rationale |
|---|---|---|
| `nonneg` (new kwarg) | `True` (default) | Imposes $\nu \ge 0$; the physically-correct constraint. Default chosen so every caller is fixed without edits. |
| Clip lower bound | `0.0` when `nonneg=True`, else `-nu_clip` | $[0,\nu_{\mathrm{clip}}]$ is exactly the scalar NNLS feasible set; the upper cap is retained for explicit-term stability. |
| `nu_clip` | `5e-4` (= `0.0005`, unchanged) | Pre-existing magnitude cap on the explicit QL term; not touched, to keep backward compatibility. |
| `ridge` | `1e-8` (unchanged) | Tikhonov regularization in the denominator of the LS ratio. |
| Verification grid | `n_t=24`, `n_k=256` | Step 0b defaults in `run_mz_derisk.py`. |
| Truncation sweep | `keep ∈ {16, 32, 64, 128}` | Step 0b default `keeps`; spans coarse to near-identity projectors ($2\cdot\text{keep}\to n_k$). |
| Truth case | constant $\sigma = 0.3$ Black–Scholes | Exact, MC-noise-free reference where the forward MZ memory's value can be read cleanly. |
| Venv | `Synthetic_Data_Tensorflow_Advanced/.venv` | Project interpreter used for all runs. |

## 5. Results

The verification driver `examples/run_mz_derisk.py` (pure NumPy/SciPy/matplotlib — no TensorFlow, no MC, no training) was run from the package root with the project venv. It exercises the *actual* `fit_nu_ql` / `integrate_rrr_ql` code paths.

**Step 0b — resolved-interior error, RRR-only vs RRR+QL.** The headline comparison, with the legacy column obtained via the `nonneg=False` escape hatch on the identical setup:

| `keep` | LEGACY `nonneg=False` ($[-\text{clip},+\text{clip}]$) | FIXED `nonneg=True` ($[0,+\text{clip}]$) |
|---|---|---|
| 16  | $\nu = -5.00\times10^{-4}$, gain **$-4.4\%$** | $\nu = +0.00\times10^{0}$, gain **$+0.0\%$** |
| 32  | $\nu = -5.00\times10^{-4}$, gain **$-7.5\%$** | $\nu = +0.00\times10^{0}$, gain **$+0.0\%$** |
| 64  | $\nu = -5.00\times10^{-4}$, gain **$-19.5\%$** | $\nu = +0.00\times10^{0}$, gain **$+0.0\%$** |
| 128 | $\nu = +1.94\times10^{-6}$, gain $+0.0\%$ | $\nu = +1.94\times10^{-6}$, gain $+0.0\%$ |

Interpretation:

- **The legacy column reproduces the documented "before" exactly** ($\nu$ pinned at $-5.00\times10^{-4}$; gains $-4.4\%/-7.5\%/-19.5\%$ at `keep`$=16/32/64$). This confirms the change is *precisely* the sign constraint and nothing else.
- **The fix gives $\nu \ge 0$ across the whole sweep** (three slices at exactly $0$, one tiny-positive). The previously negative unconstrained optimum is projected to $\nu = 0$, so the explicit QL term vanishes and RRR+QL collapses onto RRR-only — hence gain $+0.0\%$ rather than a worsening.
- **The constraint only bites when the fit wants the wrong sign.** At `keep`$=128$ the unconstrained $\nu^\* = +1.94\times10^{-6}$ was already positive, so both branches agree; the tiny positive value yields a rounded $+0.0\%$ gain (JSON `rel_gain_resolved_interior` $= +0.0431\%$).

The resolved-interior RMS errors for RRR-only were $8.490\times10^{-2}$, $9.192\times10^{-2}$, $9.602\times10^{-2}$, $1.045\times10^{-2}$ at `keep`$=16/32/64/128$; with the fix the QL errors equal them to displayed precision. The recorded JSON verdict is now `cosmetic = True`, `negative_nu_at_clip = False`, `best_rel_gain_resolved_interior = 0.000431`, and the printed verdict reads:

> _PIVOT CONFIRMED: forward QL memory does NOT improve the resolved interior at any truncation (best relative gain +0.0%) → the price-side MZ memory is not a useful contribution; the action is the density/inverse (tail) side._

The earlier addendum — "the fitted nu is NEGATIVE and pinned at the clip (anti-diffusion) … QL increases the error" — is correctly **gone**, because the anti-diffusive failure can no longer occur.

> _Note: this sharpens, not contradicts, the de-risk's prior framing. The original run reported the forward QL closure as actively **harmful** (negative $\nu$ at the clip). The corrected run shows it is **cosmetic** (no-op): once the wrong sign is forbidden, the fit sets $\nu=0$. Both runs agree the price-side forward MZ memory adds nothing on the exact constant-$\sigma$ case; the fix removes a spurious anti-diffusive artifact that was masking that conclusion as a worsening._

**Backward-compatibility check.** All five touched/adjacent modules — `quasi_linear.py`, `validation.py`, `mz_synthetic_setup.py`, `data_driven.py`, `truncation_study.py` — plus `examples/run_mz_derisk.py` compile cleanly (`py_compile`). The public signature is now:

For the record, Step 0a still reports SEED A confirmed (symmetrized generator negative-definite: const $\mathrm{spec}(L_{\mathrm{sym}}) = -2.086\times10^{-1}$, smile $-7.802\times10^{-1}$) with the known repo one-sided-stencil artifact (const $\mathrm{spec}(L_{\mathrm{repo}}) = +4.050\times10^{-1}$); Step 1 still finds `dim=1` (skew/excess-kurtosis correlation $0.990$), i.e. a single tail-energy scalar $E_{\mathrm{tail}}$ suffices. ## 7. Future Work

- **Smile / noisy cases.** The constraint was validated on the exact constant-$\sigma$ Black–Scholes case, where $\nu^\*$ is negative or near-zero. On smile surfaces or MC-noisy data the unconstrained optimum could be genuinely positive; confirm there that $\nu \ge 0$ binds rarely and that any positive QL contribution is retained. This is consistent with the study's overall pivot to the density/inverse (tail) side, where a single tail scalar $E_{\mathrm{tail}}$ is indicated.
